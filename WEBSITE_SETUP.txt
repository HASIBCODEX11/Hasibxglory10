HASIB X GLORY  -  WEBSITE + BOT PROGRAM  (V6)
==============================================
The website now handles: user login (Google or name + password), credits, 2 free trial
credits, coupons, UPI / Binance payment proof, owner panel and the Telegram bot.
This bot program (main.py) only plays the matches. web_bridge.py connects the two.

1. TELEGRAM
   The website runs your Telegram bot now. Keep TG_BOT_TOKEN EMPTY on Railway,
   otherwise the two fight over the same bot and it stops answering.
   Your token was shared in chat: open @BotFather -> /revoke -> make a new token, then
   update it on the website (Lovable -> Connectors -> Telegram).

2. RAILWAY VARIABLES (Variables tab)
   HX_WEB_URL     = your website link, e.g. https://ffglory.best
   HX_ENGINE_KEY  = website -> Owner panel -> "Telegram & bot" -> Make key -> Copy
   DATA_DIR       = /data   (with a Volume, as before)
   HX_GLORY_FIELD = optional, see below

3. HOW A SQUAD RUNS
   User spends 1 credit -> website makes a squad (4 bots, goal 100K glory per bot = 400K).
   Within 20 s this program picks it up, joins the bots to the guild and plays
   (CS / CS Rank / BR follow the website switches). Every 3 minutes it reports back.
   Goal reached / owner stops / refund -> bots of that squad switch off.
   Owner squads have no limit. Failed launch with 0 glory -> credit refunded automatically.
   Bot accounts: the website uses the accounts you upload in Owner -> Bot accounts.
   If a server has none, this program creates fresh bots like before.

4. GLORY NUMBERS
   The game's guild info reply has no documented "glory" field. Look in the log for
   "[GUILD 123...] info fields: {...}", compare with the glory you see in the game,
   and put that field number in HX_GLORY_FIELD. Until then the website shows the
   squad status but no glory number, and squads do not stop on glory by themselves
   (owner can stop them from the website).

5. AUTO RESTART
   Already built in: the supervisor restarts any stopped bot every 30 s, and Railway
   restarts the program if it crashes (railway.json restartPolicy).
